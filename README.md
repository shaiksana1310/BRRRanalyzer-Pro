# BRRRanalyzer Pro

AI-powered BRRR real estate deal analyzer. 
Paste any property description — get full investment 
analysis in 10 seconds.

🔗 Live demo: https://shaiksana1310.github.io/BRRRanalyzer-Pro/

## What it does
- Extracts property details from free-form text
- Calculates ARV, rehab costs, cash flow, BRRR strategy
- Risk scores across 9 factors
- Deal verdict with AI investment thesis

## Tech stack
- Frontend: HTML, CSS, Vanilla JavaScript
- Backend: Cloudflare Workers
- AI: Groq API (Llama 3.3 70B)
- Hosting: GitHub Pages

## How to run locally
1. Clone this repo
2. Open index.html in browser
3. Add your Worker URL to the config
